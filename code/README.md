# Code map

- `primary/`: legacy CICIoT2023 scripts for the primary grouped analysis and controls.
- `harmonized/`: 37 predictor refits, projection audits, paired 46 predictor comparisons, and ECE derivation.
- `extensions/`: matched endpoint controls, calibration, alert budget, scarcity, family exclusion, and capture order.
- `temporal/`: NF-ToN-IoT-v3 preparation, grouped allocations, chronological roles, and unknown flagging.
- `external_grouped/`: NF-ToN-IoT-v3 grouped allocation reference models.
- `pseudo_null/`: expanded random mapping reference and similarity analysis.
- `standards/`: CAPEC 3.9 informed control and source collection.
- `primary_audit/`: uncertainty recomputation and paired inference.
- `figures/build_figures.py`: figure generation from result tables.

The scripts are an archival snapshot. They retain the frozen local path contract and
some imports from the prior project. See `docs/PORTING.md` before running.
