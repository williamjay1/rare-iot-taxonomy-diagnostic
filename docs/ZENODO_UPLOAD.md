# Zenodo upload and DOI steps

1. Create a GitHub release for this repository, or download the repository ZIP.
2. Open Zenodo, choose "New upload", and upload the ZIP or connect the GitHub repository.
3. Suggested metadata:
   - Title: Reproducibility package for Diagnosing Attack Taxonomy Utility in Rare IoT Intrusion Detection
   - Upload type: Software
   - Keywords: IoT intrusion detection; attack taxonomy; rare class recall; grouped validation; reproducibility
   - Licence: MIT for code; CC BY 4.0 for derived tables and figures
   - Related identifier: the article DOI, once available
4. Publish the Zenodo record and copy the DOI in the form `10.5281/zenodo.XXXXXXX`.
5. Add the DOI to the manuscript Code Availability statement and to `CITATION.cff`.
6. Replace this placeholder sentence in the README: "A Zenodo DOI will be added after the archive is published."

Do not invent a DOI. The repository currently contains no Zenodo identifier.
